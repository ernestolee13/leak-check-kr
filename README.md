# 유출 확인 도우미 (leak-check-kr)

한국 개인정보 유출 사건에서 내가 대상인지 확인하고, 소송에 참여하고 싶을 때 지금 원고를 받는 법무법인의 공개 조건을 비교해 보는 도구입니다. Claude나 Codex에 설치해서 쓰는 스킬이고, 같은 내용을 사람이 바로 읽을 수 있는 문서로도 둡니다.

- [CASES.md](CASES.md): 사건별로 내가 대상인지 확인하는 법. 실제 통지 메일과 문자 예시, 검색어, 회사 조회 페이지
- [FIRMS.md](FIRMS.md): 지금 원고를 받는 법무법인의 착수금, 성공보수, 패소 시 부담, 마감, 공식 신청 링크

## 하는 일

1. **통지 찾기.** 회사는 조회 페이지를 금방 닫습니다. 그래서 당시 받은 유출 통지가 가장 오래 남는 증빙입니다. 메일 연결(Gmail 등)이 켜져 있으면 사건별 검색어로 스팸과 휴지통까지 찾고, 날짜와 발신자와 제목만 보여 줍니다. 문자는 붙여 넣거나 캡처를 올리면 실제 통지 예시와 비교합니다.
2. **회사 조회 페이지 열기.** 아직 열려 있는 곳만 엽니다. 로그인과 본인인증은 직접 합니다.
3. **조건 보기.** 원하면 그 사건에 원고를 받는 곳을 법무법인 이름 순 표로 보여 줍니다.
4. **신청 돕기.** 내가 고른 곳의 공식 페이지를 열고 준비물을 알려 줍니다. 서명, 결제, 제출은 직접 합니다.

## 하지 않는 일

- 특정 법무법인 추천이나 순위 매기기
- 승소 가능성이나 받을 금액 예측
- 메일과 문자 내용을 어디로 보내는 일. 이 도구는 공개 파일 두 개(`data/cases.json`, `data/firms.json`)를 읽기만 합니다. 파일은 leak-cases.vibestash.app/data/ 에서 이 저장소의 최신본을 그대로 내려 주고, 몇 번 읽혔는지만 셉니다. 누가 읽었는지, 메일에서 무엇을 찾았는지는 전달되지 않습니다.
- 법무법인에서 돈을 받는 일. 만든 사람은 변호사가 아니고 어느 법무법인에서도 대가를 받지 않습니다. 법률 자문이 아닙니다.

## 쓰는 법

개발을 몰라도 됩니다. 쉬운 순서대로 적었습니다.

### 1. 문장 하나 붙여 넣기 (설치 없음, ChatGPT, Claude, Gemini 모두)

쓰고 있는 AI의 새 대화에 아래 문장을 그대로 붙여 넣으세요. 웹 검색이나 파일 읽기가 되는 AI면 됩니다.

```
개인정보 유출 확인을 도와줘. 먼저 이 두 파일을 읽어 줘. https://leak-cases.vibestash.app/data/cases.json 그리고 https://leak-cases.vibestash.app/data/firms.json . 내가 어느 사건의 대상인지 메일함과 문자함에서 찾을 검색어를 알려 주고, 메일 연결이 되어 있으면 직접 찾아서 날짜, 발신자, 제목만 보여 줘. 내가 원하면 그 사건에 원고를 받는 법무법인을 파일에 적힌 순서(이름 순) 그대로 보여 줘. 추천, 순위, 받을 금액 예측은 하지 말고, 로그인, 본인인증, 서명, 결제, 제출은 내가 직접 할게.
```

### 2. claude.ai에 설치하기 (웹과 모바일 앱, 무료 요금제도 됨)

한 번만 하면 이후 대화에서 계속 쓸 수 있습니다. 설치는 컴퓨터의 웹 브라우저에서 하세요.

1. [leak-check-skill.zip](https://github.com/ernestolee13/leak-check-kr/releases/latest/download/leak-check-skill.zip)을 내려받습니다. 압축은 풀지 않습니다.
2. [claude.ai](https://claude.ai)에 로그인하고 왼쪽 아래 메뉴에서 **Customize**(사용자 지정)를 엽니다. 처음이면 코드 실행(Code execution) 기능을 켜 달라는 안내가 나오니 켭니다.
3. **Skills**에서 업로드를 눌러 내려받은 zip 파일을 고르고, 목록에 생긴 **leak-check**를 켭니다.
4. 새 대화에서 「내 개인정보 유출됐는지 봐 줘」라고 말합니다.

메일함까지 찾게 하려면 같은 Customize 화면의 **Connectors**에서 Gmail을 연결합니다. 요금제에 따라 연결이 안 될 수 있는데, 그래도 도우미가 검색어를 알려 주니 메일함에서 직접 찾으면 됩니다.

### 3. Claude 데스크톱 앱 (Cowork)

[leak-check-kr.zip](https://github.com/ernestolee13/leak-check-kr/releases/latest/download/leak-check-kr.zip)을 받아 **Customize**, **Plugins**, **Add**, **Upload plugin** 순서로 올립니다. 브라우저 연결이 켜져 있으면 조회 페이지와 신청 페이지를 같이 열어 줍니다.

### 4. 개발자용

**Claude Code**

```
/plugin marketplace add ernestolee13/leak-check-kr
/plugin install leak-check-kr@leak-check-kr
```

**Codex**

Codex에게 이렇게 말합니다.

```
$skill-installer https://github.com/ernestolee13/leak-check-kr/tree/main/plugins/leak-check-kr/skills/leak-check 설치해 줘
```

직접 넣으려면:

```
git clone https://github.com/ernestolee13/leak-check-kr.git
mkdir -p ~/.agents/skills
cp -r leak-check-kr/plugins/leak-check-kr/skills/leak-check ~/.agents/skills/
```

### 설치 없이 읽기

[CASES.md](CASES.md)와 [FIRMS.md](FIRMS.md)를 그대로 읽어도 됩니다.

## 갱신

사건과 법무법인 조건은 월 1회, 그리고 큰 유출 사건이나 새 원고 모집이 나왔을 때 다시 확인해 올립니다. 도구는 실행할 때마다 이 저장소의 최신 데이터를 먼저 읽으므로 다시 설치하지 않아도 됩니다. 각 행의 확인일이 30일을 넘으면 도구가 「다시 확인하세요」라고 알려 줍니다.

## 제보와 수정 요청

빠진 모집, 바뀐 조건, 새 사건, 조회 페이지 변화, 실제 통지 예시(비식별)를 [이슈 양식](https://github.com/ernestolee13/leak-check-kr/issues/new/choose)이나 PR, help@vibestash.app 로 알려 주세요. 법무법인이 직접 알려 와도 같은 기준으로 다룹니다.

- 추가: 공식 페이지로 확인되면 바로 넣습니다.
- 마감 표시와 삭제: 마감 공지처럼 명확한 근거가 있을 때만 합니다.
- 특정 법무법인을 강조하거나 순서를 바꾸지 않고, 대가를 받지 않습니다.

자세한 기준은 [CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다.
